# Ad Attribution Auditor (Next.js)

This is the **Next.js web app** version of [ad-attribution-auditor](https://github.com/neoloong/ad-attribution-auditor). See the root repo for the Python/Streamlit engine and full documentation.

## Quick Start
```bash
git clone https://github.com/neoloong/ad-attribution-auditor.git
cd ad-attribution-auditor/web
npm install
npm run dev
```
Open http://localhost:3000/dashboard?demo=true

**[Live demo →](https://ad-attribution-auditor-next.vercel.app/dashboard?demo=true)**
